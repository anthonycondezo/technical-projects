# ReadySetHire

A **full-stack** web-application, AI-powered platform which bring potential employers and employees together into one place. 

## Project Description

ReadySetHire is a modern web application designed to streamline the hiring
process. It provides recruiters with an easy way to set up interviews, add
interview questions, invite applicants, and automatically capture their spoken
responses through speech-to-text transcription. By using the latest AI
technology, ReadySetHire allows applicants to answer naturally in spoken
language, making the experience more authentic and efficient.


This tool can be used for screening applicants at scale and includes
opportunities to extend functionality with Generative AI, such as providing
feedback or auto-suggesting interview questions. In the future, ReadySetHire
could also serve as a practice platform for job seekers, helping them prepare
for interviews with realistic AI-driven simulations.

### Features

ReadySetHire allows users to:
- Create, edit, and delete Interviews
- Add interview questions
- Invite applicants through unique interview links
- Applicants answer using an audio recorder, with AI transcription
converting speech to text
- One question per page interview flow for clarity and focus
- Track interview status (Not Started and Completed)
- Review Applicant question answers
- Creative Integration of GenAI - question generator

## Set Up Guide

Before proceeding further, follow the installation guides below 
if any of the listed programs are not installed on your local machine.

- [node.js](https://nodejs.org/en/download/) 
- [postgreSQL](https://www.postgresql.org/download/)
- [postgREST](https://docs.postgrest.org/en/v13/explanations/install.html) 

Please follow the set up guide to enable hosting the web application and relervant services (llm-server and postgREST) on your local machine.

### PostgreSQL and PostgREST

Please navigate to sub-directory psql-server before proceeding: ```
    cd .\\psql-server
    ```

1) Open database_set_up.sql and update your authenticator login password on line 44 with your secure password.
    ```sql
    44  create role authenticator noinherit login password 'yourpassword';
    ```
    Execute script within psql terminal.
    ```postgres
        -- within postgres terminal
        i\ ./database_set_up.sql
    ```

2) Run terminal command to install relervant node modules dependencies.
    ```bash
        npm install # within psql-server sub-directory
    ``` 

3) Run generate.sh to generate your jwt-secret and jwt-token strings.
    ```bash
        ./generate.sh # within psql-server sub-directory
    ```

4) Open postgrest.config and update db-uri (on line 3) with the same password for the authenticator login
    ```config
        3 db-uri = "postgres://authenticator:yourpassword@localhost:5432/readysethire"
    ```
    On line 13 add your jwt-secret string generated from generate.sh
    ```config
        13 jwt-secret = "yourjwtsecret" 
    ```

5) Exit psql-server and navigate to apiRequest.js 
    ```bash
        cd ..
        cd .\\react-ready-set-hire\\src\\api-ready-set-hire-requests\\
        code .\\apiRequest.js
    ```
    Add (on line 6) your jwt-token generated by generate.sh

    ```js
        6    const JWT_TOKEN = "Please enter your JWT token here";        
    ```

### LLM Server

Please navigate to sub-directory llm-server before proceeding 
    ```
        cd .. ;
        cd .\\llm-server
    ```

6) Update supplied .env file with your own OPENAI_API_KEY on line 3.

    ```env
        3   OPEN_API_KEY=YOUR_API_KEY
    ```

7) Install llm server node module dependencies:

    ```bash
        npm install # within sub-directory llm-server
    ```

### react-ready-hire

8) Navigate to sub-directory react-ready-set-hire and install react client node module dependencies:

    ```Bash
        cd ..
        cd .\\react-ready-set-hire\\
        npm install # within sub-directory react-ready-set-hire 
    ```

## Starting Project

To start project, open three terminal windows within project directory ready-set-hire to perform the following terminal commands

### Start llm service: 

1) Terminal window 1:
    ```bash
        node ./server.js # within ready-set-hire/llm-server
    ```
### Start postgREST service:

2) Terminal window 2: 
    ```bash
        postgrest ./postgrest.config # within ready-set-hire/psql-server
    ```
### Start React client:

3) Terminal window 3: 
    ```bash
        npm start dev # within ready-set-hire/react-ready-set-hire
    ```
    Click on generated localhost link to navigate to web application.
