## Set Up Guide

Before proceeding further, follow the installation guides below 
if any of the listed programs are not installed on your local machine.

- [node.js](https://nodejs.org/en/download/) 
- [postgreSQL](https://www.postgresql.org/download/)
- [postgREST](https://docs.postgrest.org/en/v13/explanations/install.html) 

Please follow the set up guide to enable hosting the web application and relervant services (llm-server and postgREST) on your local machine.

### PostgreSQL and PostgREST

Please navigate to sub-directory psql-server before proceeding:

1) Open database_set_up.sql and update your authenticator login password (line 44). Then enter the psql terminal to execute the sql file (within psql terminal enter "\i ./database_set_up.sql")

2) Run the terminal command "npm install" to install all relervant module dependencies.

3) Run generate.sh to generate your jwt-secret and jwt-token strings. 

4) Open postgrest.config and (1) update db-uri (line 3) with the same password for the authenticator login; and (2) add your jwt-secret string (line 13) generated from generate.sh

5) Exit psql-server and open ./react-ready-set-hire/api-ready-set-hire-requests/apiRequest.js and add (line 6) your jwt-token generated by generate.sh

### LLM Server

Please navigate to sub-directory llm-server before proceeding:

6) Update the supplied .env file with your own OPENAI_API_KEY (line 3). 

7) Enter the "npm install" terminal command to install all node-module dependencies.

### react-ready-hire

Please navigate to sub-directory react-ready-set-hire before proceeding:

8) Enter the "npm install" terminal command to install all node-module dependencies.


## Starting Project

To successfully start the project, open three terminal windows within project directory ready-set-hire and perform the following terminal commands
### Terminal 1 - Start LLM service: 

1) Within sub-directory llm-server:
```markdown
    node ./server.js # within ready-set-hire/llm-server
```
### Terminal 2 - Start postgREST service:

2) Within sub-directory psql-server: 
```markdown
    postgrest ./postgrest.config # within ready-set-hire/psql-server
```
### Terminal 3 - Start client:

3) Within sub-directory react-ready-set-hire: 
```markdown
    npm start dev # within ready-set-hire/react-ready-set-hire
```
Click on generated localhost link to navigate to web application.
