# form-base

## Project Description

A Mobile App that builds custom forms for data collection
FormBase is a prototype mobile app built with Expo and React Native that
lets users create flexible data-collection forms on the fly. Each form can
include a mix of field types — text, multiline text, dropdowns, image/camera
and location (i.e. capture the users location) with options for marking fields as
required or numeric. Once a form with fields is created, users can save
records. Users can define custom filter (including numeric comparisons and
string comparisons), and visualize location results on a map. The prototype
demonstrates how lightweight, mobile-first tools can empower users to
design, collect, and explore structured data without needing a custom
backend for every use case but lacks features for editing/updating fields.

### Features

Formbase allows users to:
- Add / Edit Forms
- Add Fields to a Form (i.e. text, multiline, dropdown, location and image or camera)
- Mark fields as required or numeric
- Enter data and save as Records
- Search and filter Records with criteria (text and numeric
operators)
- View Records in a list
- Copy or Delete Records
- Visualize location-based Records on a map

## Set Up Guide

Before proceeding further, follow the installation guides below 
if any of the listed programs are not installed on your local machine.

- [node.js](https://nodejs.org/en/download/) 
- [postgreSQL](https://www.postgresql.org/download/)
- [postgREST](https://docs.postgrest.org/en/v13/explanations/install.html) 

Furthermore, on your android device, please install [Expo Go](https://play.google.com/store/apps/details?id=host.exp.exponent&hl=en_AU), which will allow you to access the formbase app from your android device directly.

Please follow the set up guide to enable hosting the web application and relervant services (i.e. postgREST) on your local machine.


### PostgreSQL and PostgREST

Please navigate to sub-directory psql-server before proceeding: ```
    cd .\\psql-server
    ```

1) Open database_set_up.sql and update your authenticator login password on line 33 with your secure password.
    ```sql
    33  create role authenticator noinherit login password 'yourpassword';
    ```
    Execute script within psql terminal.
    ```postgres
        -- within postgres terminal
        i\ ./database_set_up.sql
    ```

2) Run terminal command to install relervant node modules dependencies.
    ```bash
        npm install # within psql-server sub-directory
    ``` 

3) Run generate.sh to generate your jwt-secret and jwt-token strings.
    ```bash
        ./generate.sh # within psql-server sub-directory
    ```

4) Open postgrest.config and update db-uri (on line 3) with the same password for the authenticator login
    ```config
        3 db-uri = "postgres://authenticator:yourpassword@localhost:5432/formbase"
    ```
    On line 13 add your jwt-secret string generated from generate.sh
    ```config
        13 jwt-secret = "yourjwtsecret" 
    ```
5) 
   Exit psql-server and run get_address.ps1 to identify the IPv4 address of your local machine. 
    ```bash 
        .\\get_address.ps1 # within project directory form-base
    ```

6) Navigate to apiRequest.js 
    ```bash
        cd ..
        cd .\\react-native-form-base\\formbase-api\\
        code .\\api-request.js
    ```
    and update (on line 2) the API_BASE_URL string to include the IPv4 address of your local machine identifed by get_address.ps1

    ```js
        2   const API_BASE_URL = "http://YourIpv4Address:3000";
    ```
    
    then add (on line 5) your jwt-token generated by generate.sh

    ```js
        5    const JWT_TOKEN = "Please enter your JWT token here";        
    ```

    ### form-base
7) Run terminal command to install relervant node module dependencies. 
    ```Bash 
    cd ..
    npm install # within sub-directory react-native-form-base
    ```

## Starting Project

To start project, open two terminals windows within project directory form-base to perform the following. Please ensure that your local machine and android device are both connected to the same local network.

### Start postgREST service:

1) Terminal window 1: 
    ```bash
        postgrest ./postgrest.config # within form-base/psql-server
    ```

### Start React client:

2) Terminal window 2: 
    ```bash
        npx expo start # within form-base/react-native-form-base
    ```
    Scan generated QR code to navigate to the app from your android device.
